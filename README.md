# Brackeys-2026.2
Our game for Brackeys Game Jam 2026

Game jam theme: *Trust No One*


You're a worker at a factory, business as usual, but something feels off... The owner of the factory, your very good friend who pretended to work with you, had forcefully trapped everyone in it. The very friend you had trusted the most..

Playable url: https://alimad.itch.io/brackeys26

For editing, install Unity, then clone this git repo and open the folder in it.
